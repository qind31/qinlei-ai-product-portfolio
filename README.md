## 项目概览：餐饮 AI 营销助手

| 维度 | 内容 |
| --- | --- |
| 目标用户 | 缺少专业内容团队、需要持续生产营销素材的中小餐饮门店 |
| 核心问题 | 营销卖点难提炼、短视频脚本难策划、内容制作流程繁琐 |
| 产品方案 | 商家资料 → AI 营销方案 → M001 分镜配置 → 字幕与视频渲染 |
| 我的职责 | 产品规划、需求拆解、AI 工作流设计、技术路线评估、项目推进与验证 |
| 当前进展 | 基础功能与关键技术链路已完成阶段性验证；多镜头视觉仍在实验；一键成片与商业化上线尚未完成 |

**产品思路：** 不是简单地把 AI 接入视频生成，而是围绕商家的内容生产流程，将经营资料转化为营销方案，再逐步完成分镜、素材与视频输出。

## 项目成果与说明

本作品集重点展示产品策划、AI 应用实践与技术链路验证成果。

- 已完成 AI 营销方案生成、方案保存读取、分镜配置及中文字幕 MP4 渲染等阶段性验证。
- 已完成一次基于真实授权资料的测试成片链路验证。
- 已开展多镜头动态效果实验，并根据测试反馈调整方案。
- 项目尚未商业化上线，自动化配音、BGM、一键成片及规模化业务验证仍在后续计划中。
